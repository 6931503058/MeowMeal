## Traceability Matrix (Golden Thread)

| Problem / Pain | Requirement (FR) | Solution / Design | Feature Built | Test |
| :-------------- | :--- | :--- | :--- | :--- |
| Discharged post-op/chronic cats lack static baselines; caregivers forget specific vet-prescribed target volumes during home recovery. | **FR-1** Add / edit cat profile | Local storage data model & form validation for cat baseline attributes (name, age, weight, diagnosis context, and daily intake target %). | Cat profile & settings view (`#view-profile`), validation logic (`profile.js`), and persistent profile banner on Home screen. | `test_save_valid_cat_profile()`<br>`test_reject_invalid_target_percentage()` |
| Mushy wet recovery food smears unpredictably and fails camera logging in low light; caregivers need reliable manual entry. | **FR-2** Log meal intake manually | Tactile, high-contrast button grid (0%, 25%, 50%, 75%, 100% remaining) with prescription diet selector and isolated outlier snack logging (`isOutlier = true`). | Manual meal logger (`#view-log`, `log.js`) and separate Extra Snack tracker (`#view-snack`, `snack.js`) excluded from baseline calculations. | `test_manual_meal_percentage_calculation()`<br>`test_snack_excluded_from_daily_baseline()` |
| Cats conceal illness; owners overlook subtle consecutive appetite loss until severe complications occur. | **FR-3** Early intake anomaly alert (Golden Thread) | Anomaly Detector service running a daily aggregation check against a 5-consecutive-day drop below prescribed target. | Server-side alert job + push notification dialog prompting vet consultation (`anomaly_detector.js`, `alerts.js`, 5-day tracker on Home). | `test_trigger_alert_on_5_consecutive_days()`<br>`test_reset_counter_on_normal_meal()` |
| Vets need longitudinal intake evidence, but owners rely on vague memory. | **FR-4** Historical intake trend view | 30-day time-series data aggregation paired with a responsive line/bar chart comparing daily intake against the prescribed target line, plus an empty-state fallback. | Interactive 30-day Recovery Trend dashboard using Chart.js (`#view-trend`, `trend_dashboard.js`) with `"No logs available"` empty state. | `test_render_30_day_chart_with_logs()`<br>`test_display_empty_state_when_no_logs()` |
| Manual visual estimation of mushy/wet prescription diet is tedious and inconsistent across different household members. | **FR-5** Visual remaining food estimation (AI) | Mobile camera capture & gallery upload pipeline (`capture="environment"`) with image preview, retake capability, and automated pre-fill of estimated remaining percentage. | Bowl photo uploader & preview component (`photo.js`) integrated into `#view-log` with manual override support. | `test_image_upload_and_preview_render()`<br>`test_prefill_percentage_from_photo_estimate()` |
